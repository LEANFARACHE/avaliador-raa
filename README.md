# Avaliador de RAA · UFPA

Ferramenta de apoio à avaliação dos Relatórios Anuais de Atividades (RAA) das unidades da UFPA, feita para a Diretoria de Informações Institucionais (Dinfi/Proplan).

**Abrir:** https://leanfarache.github.io/avaliador-raa/

- A página roda inteira no navegador: os PDFs são lidos no próprio computador e não vão para servidor algum.
- A sugestão de notas por IA usa o Gemini com uma chave gratuita do Google AI Studio. A chave é colada em Configurações e fica guardada só no navegador de quem usa.
- Este repositório guarda só a página pronta (`index.html`). O código-fonte e os testes ficam com a equipe.
